## Como trabalho

Procuro entender o problema antes de escolher a solução. Organizo interfaces em componentes reutilizáveis, separo acesso a dados das regras da tela e valido o resultado em diferentes tamanhos de dispositivo.

Utilizo ferramentas de inteligência artificial como apoio para pesquisa, produtividade e revisão. O código publicado é analisado, adaptado e mantido por mim, e consigo explicar as decisões técnicas dos projetos apresentados.
