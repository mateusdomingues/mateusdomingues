# D&S Construção

> Projeto comercial real para uma empresa de construção civil. O repositório permanece privado.

## Contexto

A D&S Construção precisava de uma presença digital capaz de transmitir confiança, explicar sua atuação do início da obra à entrega e facilitar o contato de novos clientes.

## Minha participação

Desenvolvi a estrutura do site, a identidade visual aplicada à interface, o comportamento responsivo, as animações, o SEO técnico e a publicação na Vercel.

## Solução

O projeto combina uma apresentação institucional objetiva com direção visual editorial. A navegação conduz o visitante pelos serviços, processo de trabalho, diferenciais e contato comercial.

## Principais entregas

- Interface responsiva
- Identidade visual aplicada ao ambiente digital
- Preloader personalizado
- Animações e transições
- Metadados para mecanismos de busca e compartilhamento
- Sitemap, robots e manifest
- Dados estruturados com Schema.org
- Integração com WhatsApp
- Configuração para indexação
- Deploy contínuo na Vercel

## Tecnologias

Next.js, React, TypeScript, Framer Motion, Tailwind CSS e Vercel.

## Decisões técnicas

- Uso do App Router para organizar a aplicação
- Metadados centralizados no layout
- Dados estruturados descrevendo organização e website
- Tipografia otimizada com carregamento pelo Next.js
- Conteúdo orientado para conversão sem sacrificar desempenho

## Desafios trabalhados

O projeto começou sem uma identidade digital consolidada. O desafio foi criar uma apresentação coerente e confiável, além de preparar corretamente a página para indexação e compartilhamento.

## Resultado

Site comercial publicado, responsivo e indexável.
